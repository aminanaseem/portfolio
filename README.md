# Amina Naseem — Portfolio

An animated, interactive single-page portfolio for **Amina Naseem**, a Cybersecurity & Digital Forensics professional.

## ✨ Features

- **Animated Interactive Theme** — Matrix rain background, floating particles, custom cursor, swirl gradients
- **Preloader** — Terminal-style loading screen
- **Typed Hero** — Rotating role text with a blinking cursor
- **Scroll Reveal Animations** — Sections fade/slide in as you scroll
- **Animated Counters** — Stats count up when visible
- **Interactive Marquee** — Tilted scrolling strip of specialties
- **Project Filtering** — Filter projects by domain (Forensics, AI/ML, Web Dev, Automation, Network)
- **Certificate Gallery** — Lightbox-enabled image gallery of certificates
- **Contact Form** — Opens the user's email client with a pre-filled message
- **Fully Responsive** — Works on mobile, tablet, and desktop

## 🔧 Technology

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, flexbox, grid, keyframe animations
- **Vanilla JavaScript** — Typed effect, scroll spy, counters, filter, lightbox, matrix canvas

No build step or dependencies required — just open `index.html` in a browser.

Open `index.html` in any modern browser. For best results with the heavy animations, use a recent version of Chrome, Edge, or Firefox.
